# Security Policy

## Public-Safe Boundary

This repository is designed as a public-safe, local-first prototype.

## Security Rules

```text
External Action: BLOCKED
Real Data: PROHIBITED
Synthetic Data: ONLY
Human Review: REQUIRED
Commercial Core: PROTECTED
External Effect: BLOCKED
```

## Do Not Submit

Do not submit real personal data, legal documents, medical information, credentials, API keys, private addresses, case numbers or confidential files.

Do not upload real case files, real screenshots, private letters, account data, government documents, medical documents or any other sensitive source material.

## Reporting

If you find a safety issue, open a GitHub issue without sensitive details. Do not include credentials, personal data, tokens, cookies, private documents or real case details in issues.

Before public release, the security contact and vulnerability-reporting process must be reviewed so sensitive details can be reported without public disclosure.

## No External Action

This project must not send messages, submit documents, contact authorities, contact courts, run external scans or execute productive agent write actions.

This public repository does not authorize any external action or production workflow.

## Human Review

All outputs require human review before any external use. Payment, sponsorship or support does not remove this requirement.

## Credential Handling

Never commit credentials, API keys, access tokens, private keys, cookies or secrets. If a secret is suspected, stop work and rotate it outside this repository.
