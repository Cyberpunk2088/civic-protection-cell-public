# Security Policy

## Public-Safe Boundary

This repository is designed as a public-safe, local-first prototype.

## Security Rules

```text
External Action: BLOCKED
Real Data: PROHIBITED
Synthetic Data: ONLY
Human Review: REQUIRED
Commercial Core: PROTECTED
```

## Do Not Submit

Do not submit real personal data, legal documents, medical information, credentials, API keys, private addresses, case numbers or confidential files.

## Reporting

If you find a safety issue, open a GitHub issue without sensitive details.

## No External Action

This project must not send messages, submit documents, contact authorities, contact courts, run external scans or execute productive agent write actions.
