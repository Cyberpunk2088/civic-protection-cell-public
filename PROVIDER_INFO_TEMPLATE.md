This template is for completing provider information before any public release, public offer, support page, payment page or commercial landing page is used.

It is not legal advice and may require jurisdiction-specific review.

## Public Contact Route

A public release should use a dedicated public contact address, not private operational addresses.

Recommended:

```text
General contact: [PUBLIC CONTACT EMAIL]
Security contact: [PRIVATE SECURITY REPORTING EMAIL OR PROCESS]
Commercial inquiries: [COMMERCIAL EMAIL]
```

## Provider Information Review Checklist

Before public release, confirm:

- provider name is correct
- address is correct
- public contact route is controlled
- no private or family contact data is exposed accidentally
- register / VAT data is correct if applicable
- content responsibility wording is reviewed if required
- payment page uses the same provider identity
- privacy notice uses the same controller identity
- terms use the same provider identity

## Safe Placeholder Notice

Until reviewed and completed, public pages should use:

```text
Provider information is being finalized before public release. This private repository is not yet a public commercial offer.
```
