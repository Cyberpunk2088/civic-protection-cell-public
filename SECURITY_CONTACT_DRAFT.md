# Security Contact Draft

Status:

```text
SECURITY_CONTACT: DRAFT_ONLY
PUBLIC_RELEASE: BLOCKED
HUMAN_APPROVAL: NOT_GIVEN
```

Public GitHub issues must not include secrets, credentials, tokens, cookies, private keys, real case files, personal data or sensitive vulnerability details.

A private security reporting channel must be selected before any public release. The channel should allow responsible reporting without forcing public disclosure of sensitive details.

This draft does not create a final contact address or reporting process. Provider identity, privacy handling and response expectations must be reviewed before publication.
