# Public Release Checklist

Status:

```text
PUBLIC_RELEASE: BLOCKED
HUMAN_APPROVAL: NOT_GIVEN
HUMAN_APPROVAL.md: ABSENT
```

Public release requires all of the following before any visibility change, release tag, package publication or deployment:

- Legal review complete.
- Provider information complete.
- Privacy notice complete.
- Payment and consumer terms complete.
- Refund and withdrawal wording complete where required.
- Tax and invoice handling reviewed.
- Security contact process complete.
- Final CI observed successfully.
- Protected core excluded.
- No real data.
- No secrets.
- No external-action logic.
- Repository visibility decision made by the owner.
- `HUMAN_APPROVAL.md` created only after explicit owner approval.

This checklist does not approve publication. It records unresolved preconditions.
