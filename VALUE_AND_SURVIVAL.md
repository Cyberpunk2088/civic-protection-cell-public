# Value and Sustainability Policy

## Principle

Public work should create real benefit and remain sustainable for the builder.

## Public Layer

This repository may provide public-safe documentation, synthetic examples, tests and non-production review-gate logic.

The public layer may include:

- documentation
- synthetic examples
- tests
- local demo
- non-production review-gate logic
- safety policies
- audit reports without private data

## Protected Layer

Production workflows, premium templates, implementation guides, custom automations, client-specific logic and commercial setup methodology may remain private, paid or separately licensed.

Protected material includes real case files, operator notes, premium templates, customer-specific setup methods, production workflows and commercial implementation methodology.

## Commercial Use

Commercial use may require written permission, a commercial license, paid setup, support agreement or implementation contract.

## Fair Value Exchange

```text
Public trust.
Protected value.
Fair exchange.
Sustainable work.
```

Payment or support does not approve public release, external action, production use or commercial rights beyond a separate written agreement.
